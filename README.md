# Cardboard Box Index SK/CZ

Tok vlnitých krabíc cez Slovensko a Česko ako predstihový ukazovateľ maloobchodu.

Stránka: https://petijeee.github.io/cardboard-box-index/

- `data/` pôvodné mesačné série z Eurostatu (Comext DS-045409, sts_inpr_m, sts_trtu_m)
- `index.html` grafy aj výpočty (báza 2021 = 100, kĺzavé priemery, korelácia podľa posunu, regresia) bežia v prehliadači

Hlavný výsledok: SK krabice korelujú s objemom maloobchodu o 6 mesiacov neskôr (r = 0,60 bez rokov 2020 a 2021). České nie.
